# harness-agents-win32-x64

The Windows x64 binaries of [ha](https://github.com/DEVfancybear/harness-agents). Do not install this package directly: `npm install -g harness-agents` pulls it in and puts `ha` on your PATH.

It holds `ha.exe`, the pinned `uv.exe` the Python kernel builds its environment with, `ha.release.json` (version, rustc, source revision and the executable's digest) and `checksums.txt`.
