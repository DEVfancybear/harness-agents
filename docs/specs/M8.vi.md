# SPEC M8 — Durable DAG và worktree integration

**Assignment:** M8-01..M8-04 (một milestone, gate riêng) · **Base revision:** `e5ef55c` · **Working tree lúc viết SPEC:** sạch

[Runbook M8](../implementation-next/M8.vi.md) · [Contracts](../implementation-next/CONTRACTS.vi.md) §8 · [Acceptance A27–A30](../implementation-next/ACCEPTANCE.vi.md) · [Evidence M7](./../evidence/M7.vi.md) · SPEC này là tài liệu trước code

## 1. Goal / non-goals

**Goal.** Bốn work item M8 nối vào orchestrator đang có: DAG/brief/scheduling đã bị chặn đúng (M8-01), child
result + parent delivery là một transaction và chịu được duplicate (M8-02), worktree là biên concurrency và
integration từ chối ghi đè (M8-03), và acceptance cuối cùng đọc bằng chứng trên **cây đã tích hợp** chứ không
phải trên revision của từng branch (M8-04).

**Non-goals.** Không remote worker; không recursive unlimited agents; không auto merge/push; không hỗ trợ dirty
snapshot khi chưa có proof. Không thêm bảng cho M9 (retention/backup). Không đổi `ha` subcommand hiện có theo cách
phá vỡ output.

## 5. CLI integration

```text
ha run agents / ha status / ha result / ha cancel      (delegation_cli.rs)
  -> DelegationCoordinator::{admit, claim, dispatch, await_next, settle, durable_progress, durable_result}
  -> WorkerScheduler (permits, queue, drain) -> WorkerBackend (real engine hoặc fixture)
  -> SqliteStore::delegation (task nodes, owners, deliveries, worktrees, integrations)
  -> WorkspaceManager (git worktree) / ResultIntegrator (apply + recheck)
```

Mỗi thứ thêm ở M8 phải có caller thật từ đường này, kể cả nhánh lỗi/cancel/restart.

## 6. Compatibility

- Không đổi `DELEGATION_CONTRACT_VERSION` (=1) trừ khi thêm field **bắt buộc** vào `TaskBrief`/`DelegatedResult`; field
  mới phải optional hoặc có default để store cũ đọc được. Không đổi `EXTENSION_PROTOCOL_VERSION`/`TOOL_CONTRACT_VERSION`/
  `CONTEXT_SCHEMA_VERSION`/`MEMORY_SCHEMA_VERSION`.
- Nếu cần cột/bảng mới: `DELEGATION_SCHEMA_VERSION` tăng theo cùng change, kèm fixture "store phiên bản trước mở bằng
  host này" và recovery; **không** dồn compatibility sang M9.
- `ha run agents`/`status`/`result`/`cancel`: giữ subcommand và field cũ; field mới là **thêm**.
