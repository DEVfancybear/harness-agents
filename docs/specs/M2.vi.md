## 1. Goal / non-goals

Goal: xác minh protocol provider hiện có, đóng các gap thật để A06/A07 thành acceptance case có selector, và giữ một provider engine duy nhất đi từ `ha` qua runtime/TurnDriver.

- **M2-01** typed assistant calls/tool results + validate correlation/duplicate/ordering; capability registry tri-state (supported / explicitly false / unknown) và reject unsupported params.
- **M2-02** SSE assembler có state: parse bytes→UTF8→frame→payload→normalized deltas với **limits**; accumulate theo `(choice,index)`; tách terminal/finish/usage-only/EOF/length/refusal; backpressure.
- **M2-03** transport: taxonomy lỗi HTTP typed, timeout, cancellation-aware, retry ownership rõ (runtime sở hữu retry, adapter không retry), không lộ token.
- **M2-04** conformance harness (fake HTTP server có barrier) + chạy cùng scenario cho mock và DeepSeek adapter; live smoke optional (không chạy, không credential).

Non-goals: provider thứ hai, live credentials trong fixture, tool execution (M4), full runtime (M3), thay đổi store/schema (M1 đã chốt).

## 5. Contract decisions (ADR-N04 — canonical messages, capabilities, terminal semantics)

Ghi tại `docs/adr/ADR-N04-PROVIDER-PROTOCOL.vi.md` (+ `.en.md`):

1. **Canonical vs wire.** `ProviderMessage` là canonical model; `to_wire` là encoding của adapter Chat Completions. Tool result vẫn được encode thành user message có marker **vì** endpoint đã đo từ chối `tool` role thiếu `tool_call_id` và không nhận tool calls giữa hội thoại; canonical model mang `tool_call_id` để validate correlation, wire không đổi.
2. **Protocol validator trước dispatch.** Runtime validate transcript (correlation, duplicate call IDs, ordering) trước khi freeze; lỗi typed `ProviderProtocol`.
3. **Capability claims tri-state.** `Supported` / `Unsupported` / `Unknown`: `Unsupported` ⇒ từ chối request dùng parameter đó (`IncompatibleService`); `Unknown` ⇒ cho phép nhưng không được coi là bằng chứng tương thích.
4. **Terminal semantics.** `[DONE]` → `Completed("stop")`; frame có `finish_reason` → `Completed(reason)`; usage-only frame → `Usage` (không mất); EOF/mất terminal → quan sát được qua `finish_reason: None`; tool call không có terminal **không dispatchable**.
5. **Retry ownership.** Adapter không retry; runtime retry theo `RetryClass` + `max_attempts`, có cap cho `Retry-After`. 401/403 không retry.
6. **Redaction.** Error chỉ mang status/typed code, không mang token/body; test sentinel phải chứng minh.
7. **Capability matrix** DeepSeek pin tại M2 (nguồn: `api-docs.deepseek.com/quick_start/pricing` và `/quick_start/error_codes`, đọc ngày 21/09/2026):
   - Base URL (OpenAI format) `https://api.deepseek.com`; Anthropic format `/anthropic`; chat completions path do `chat_completions_endpoint` chuẩn hóa.
   - Model hiện hành: `deepseek-flash` (legacy `deepseek-v4-flash`, `deepseek-v4-flash-vision-exp` vẫn được chấp nhận) và `deepseek-v4-pro`; cả hai hỗ trợ Tool Calls và streaming; Vision chỉ ở dòng flash.
   - Thinking mode **mặc định bật** → app gửi `thinking: disabled` (đã đo ở P2: bật thinking buộc phải gửi lại `reasoning_content`).
   - Error table (nguồn chính thức): 400 Invalid Format, 401 Authentication Fails, 402 Insufficient Balance, 422 Invalid Parameters ⇒ **không retry**; 429 Rate Limit, 500 Server Error, 503 Server Overloaded ⇒ transient, retry bounded.
   - Không hardcode pricing; `ModelCapabilities::deepseek_fixture()` vẫn là fixture (model `deepseek-chat`) và không phải bằng chứng tương thích live.

## 6. Fixture oracle

| Oracle | Nội dung | Kỳ vọng |
|---|---|---|
| SSE golden stream | frame text + 2 tool call xen kẽ + usage-only + `[DONE]`, chia chunk ở mọi ranh giới byte | events đúng thứ tự; 2 call giữ ID/name; usage giữ; `Completed("stop")` |
| ID conflict | cùng `(choice,index)` announce 2 ID khác nhau | `ProviderProtocol` typed, không call nào được dispatch |
| Limits | buffer vượt cap / frame vượt cap / calls vượt cap / args vượt cap | `FrameLimitExceeded` / `OutputLimitExceeded` |
| Truncated tool args | args JSON không hoàn chỉnh | `incomplete_tool_calls = true`, không dispatchable |
| Missing terminal | stream kết thúc không `[DONE]`/finish_reason, có tool call | `finish_reason == None` ⇒ không dispatchable |
| HTTP taxonomy | server trả 401 / 429 (Retry-After) / 503 / 400 / hang | 401 → 1 attempt, `MissingAuthority`; 429/503 → retry bounded; 400 → no retry; hang → cancel/timeout typed |
| Redaction | token sentinel `sk-m2-sentinel` | không xuất hiện trong error/stdout/stderr/log |
| Conformance | cùng SSE script qua mock và adapter | cùng normalized response (text/calls/finish) |

## 9. Compatibility

- Wire format không đổi (`wire_tests` giữ pass); `ProviderMessage` thêm field additive với `#[serde(default)]`.
- `ProviderStreamEvent` thêm variant `Usage` (additive; consumer cũ bỏ qua).
- Không đổi store/schema/config/CLI command nào.
- Retry policy chặt hơn ở đúng một điểm: lỗi retry class `Never` (401/403/400) không còn được retry — đúng A07, cần nêu trong evidence.
