# Đặc tả triển khai P6 — skills, MCP và protocol plugin bên ngoài

[English](P6.en.md) | Tiếng Việt

Trạng thái: **đặc tả triển khai đang hiệu lực**. SPEC này chỉ cấp quyền cho
P6-S01 đến P6-S07. Nó không cấp quyền cho P7 release hardening hay P8 Web UI, và
không cấp quyền cho marketplace, Wasm, native dynamic loading tùy ý, hoặc plugin
loop/storage bên ngoài. Publish (commit và push) đã được user yêu cầu rõ cho
assignment này; không được publish gì khác.

## 1. Prerequisite và source boundary

Base revision `0ba1a10` trên `origin/master`, working tree sạch. P5 đã được chấp
nhận trước khi bất kỳ code P6 nào được viết: gate local và CI remote đều xanh.

Phần xác minh tiền nhiệm đã chạy cho P6:
`pwsh -NoProfile -File scripts/Verify-Phase.ps1 -Phase P5 -Json` pass với digest
`sha256:761ce949f3f218410899b540eb3872ba660a4a79d58086e26a71c14fcf4c2706`
(171 file), 19/19 required test, 27 test được discovery, và regression tiền nhiệm
P0 8 / P1 23 / P2 15 / P3 18 / P4 20 đều xanh. Lần chạy CI remote `35109453587`
báo success cho P5 trên ubuntu-latest và windows-latest.

P6 bảo toàn: schema revision và ID format của store từ P0/P1, single SQLite writer
và host fencing, đường admission frozen request/context của P2, policy gate và
immutable receipt của P3, scoped memory contract của P4, và
delegation/DAG/worktree contract của P5. Extension không được làm yếu durability,
policy hay scoped memory.

## 2. Scope và kiến trúc được chọn

- Tạo `crates/harness-extensions/` làm owner của protocol plugin bên ngoài: trust
  và capability contract, bounded stdio transport, external tool bridge, external
  model-provider bridge, MCP client adapter, và skills/profile composition.
- External tool **chỉ** được expose qua gate P3 hiện có trong `harness-tools`.
  Bridge thêm một dispatch hook sau khi durable intent được commit; nó không thêm
  đường authorization thứ hai.
- `harness-kernel` vẫn là owner của plugin graph, scoped registry, lease,
  generation và resource lifecycle. P6 đăng ký extension như kernel resource để
  unload/reload và shutdown có thứ tự tiếp tục hoạt động.
- MCP client dùng official `rmcp` SDK đã pin. MCP negotiation là contract riêng
  của SDK và không bao giờ được mặc định tương thích với custom plugin protocol
  của crate này.
- Mở rộng CLI bằng plugin/config inspection và đường cài/đăng ký local được cấp
  quyền rõ, cùng acceptance target `phase_p6`.

Trong scope: local stdio extension, local MCP fixture server, filesystem skill có
version, trusted profile composition, capability negotiation, unload/reload với
generation, và compatibility evidence.

Ngoài scope: marketplace, Wasm, native dynamic loading tùy ý, remote MCP endpoint
vượt quá một trust/network policy đã tài liệu hóa, plugin loop hoặc storage bên
ngoài, inject context sau freeze, và mọi kiểu tải package ngầm.

## 3. Contracts cần chốt trước implementation

1. **Identity.** Plugin khai báo `plugin_id`, `implementation_version`, digest
   build/content, version `ServiceContract` được cung cấp và yêu cầu, version
   config schema, capability được yêu cầu, restart policy và việc thiếu nó có
   chặn recovery hay không. Implementation SemVer, host protocol version và event
   schema version vẫn là các compatibility check tách biệt.
2. **Handshake trước khi nhận việc.** Handshake mang host protocol range, plugin
   identity kèm digest, capability được quảng bá kèm version, và các schema
   version mà nó hiện thực. Digest không khớp, protocol ngoài range được hỗ trợ,
   capability version không được hỗ trợ hoặc host method được yêu cầu nằm ngoài
   allowlist đều bị từ chối trước khi bất kỳ input nào được admission.
3. **Framing và giới hạn.** Chỉ dùng newline-delimited UTF-8 JSON. Frame lớn hơn
   giới hạn đã pin là protocol error, không phải buffer vô hạn. stdout chỉ mang
   protocol frame; stderr được capture thành log có giới hạn và không bao giờ
   được parse như protocol. Response ID phải khớp đúng một lần với một request
   đang chờ; frame trùng, không rõ hoặc sai định dạng là protocol error.
4. **Bounded concurrency và cancellation.** Inflight call có giới hạn. Cancel và
   EOF/exit là tường minh: call không bao giờ nhận được response có outcome
   **uncertain** thay vì một success được dựng ra, và process tree bị dừng khi
   deadline hết.
5. **Trust.** Đọc file repository hay profile không chạy gì cả. Load một
   executable hoặc resolve một secret cần trust grant tường minh ở mức user, pin
   digest và một tập capability được phép. Plugin process chạy với environment tối
   thiểu: không kế thừa thứ mang secret, và không host credential nào được đặt vào
   environment của fixture.
6. **Authority.** Host gán call ID, principal, scope, workspace root và grant.
   Permission do plugin yêu cầu chỉ là request, không phải authority, và không bao
   giờ được vượt quá grant của parent. Nested call giữ parent invocation ID để
   tương quan.
7. **Skills.** Skill có identity, version, digest và provenance, được discovery
   lazy, và nội dung của nó là data: nó không thể tạo ra tool permission. Skill
   text chỉ vào context qua context builder P2, thành phần duy nhất admission và
   freeze block. Skill update chỉ trở nên hiển thị tại một boundary được ghi lại.
8. **Unload/reload.** Unload một extractor, tool hay provider giữ nguyên job,
   cursor và session evidence. Reload tạo generation mới; disposer đến muộn từ
   generation cũ không thể gỡ bỏ bản thay thế. Remount không bao giờ cấp quyền
   lặp lại một side effect.

## 4. Giới hạn được pin

Các tài liệu kiến trúc cố ý không chốt con số frame hay timeout, nên P6 freeze
chúng ở đây và test chúng.

| Giới hạn | Giá trị | Lý do |
|---|---|---|
| `EXTENSION_PROTOCOL_VERSION` | 1 | Có version độc lập với host API và event schema. |
| `MAX_FRAME_BYTES` | 1 MiB | Giới hạn một NDJSON frame; quá lớn là protocol error. |
| `MAX_STDERR_BYTES` | 64 KiB | Diagnostics có giới hạn cho mỗi extension instance. |
| `MAX_INFLIGHT_CALLS` | 4 | Giới hạn call đồng thời tới một extension. |
| `HANDSHAKE_TIMEOUT_MS` | 5 000 | Handshake im lặng hoặc chậm thì fail closed. |
| `DEFAULT_CALL_TIMEOUT_MS` | 30 000 | Deadline mặc định trước khi dừng process tree. |
| `MAX_SKILL_BYTES` | 256 KiB | Giới hạn một skill document đọc tại admission. |

## 5. Failure model

| Failure mode | Phòng vệ |
|---|---|
| Frame sai định dạng, quá lớn hoặc không phải UTF-8 | Typed `extension_protocol_error`; call fail, instance unhealthy, không admission. |
| Response ID trùng hoặc không rõ | Bị từ chối; pending call tương ứng không bị settle bởi ID giả mạo. |
| Output flood trên stderr | Capture có giới hạn; phần dư bị bỏ, không bao giờ là memory vô hạn. |
| Cancel bị bỏ qua | Deadline hết, process tree bị dừng, outcome là uncertain. |
| Crash trước side effect | Call báo uncertain; restart không bao giờ tự retry một call mang tính mutation. |
| Crash sau side effect | Durable intent còn nguyên; reconciliation là tường minh, không bao giờ retry mù. |
| Plugin xin một secret chưa được grant | Bị từ chối bằng typed denial trước khi process khởi động. |
| Repository profile xin load một executable | Bị từ chối nếu không có trust tường minh của user; đọc config không chạy gì cả. |
| Nested/MCP call cố bỏ qua policy | Cùng gate P3; child call được tương quan với parent invocation ID; grant được giao nhau. |
| Arguments đổi sau approval | Approval binding mất hiệu lực; execution bị từ chối. |
| Schema version thay đổi | Phải renegotiate trước khi dùng; critical schema không được hỗ trợ chặn resume. |
| Disposer đến muộn sau reload | Registration undo gắn với generation và không thể gỡ bỏ bản thay thế. |
| Skill text cố cấp permission | Skill content là data; authority vẫn đến từ grant của host. |

## 7. Test và gate

Acceptance target là `crates/harness-cli/tests/phase_p6.rs` cùng các module bổ
sung bên cạnh. Test dùng `SqliteStore` thật, gate và receipt P3 thật, kernel
registry và shutdown coordinator thật, và **process** extension thật được khởi
động từ fixture binary đã biên dịch. Không có fake in-process nào thay thế
transport. Các boundary bên ngoài thật sự ngoài scope (remote MCP endpoint, model
API trả phí) không được chạy.

Gate cuối:

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --all-targets --locked
cargo test -p harness-cli --test phase_p6 --locked
pwsh -NoProfile -File scripts/Verify-Phase.ps1 -Phase P6 -Json
pwsh -NoProfile -File scripts/Verify-Docs.ps1 -SelfTest
```

Discovery phải không rỗng và không được ignore required case; regression tiền
nhiệm P0–P5 chạy bằng exact test name. Transport isolation **không** được quảng bá
như OS sandboxing: phase này cung cấp một protocol có giới hạn, một environment
tối thiểu và một method surface nằm trong allowlist, không phải confinement cho
untrusted native code.

## 8. Setup, dependency và Git

Dự kiến có một external dependency mới:

- `rmcp` (official Rust MCP SDK, Apache-2.0), pin ở đúng một version với
  `default-features = false` và chỉ bật các feature client cùng child-process
  transport cần thiết. Không ghi "latest" ở bất kỳ đâu.

Mọi thứ còn lại tái dùng dependency workspace đã pin sẵn trong `Cargo.lock`
(`tokio`, `tokio-util`, `serde`, `serde_json`, `thiserror`, `uuid`, `sha2`,
`process-wrap`). Không cài tool hệ thống, credential, dịch vụ trả phí hay database
ngoài. Fixture plugin được biên dịch trong chính repository này và chạy với
environment tối thiểu không chứa secret thật.

Thay đổi dự kiến nằm trong `crates/harness-extensions/`, phần additive của
`harness-tools`, `harness-providers`, `harness-kernel`, `harness-runtime`,
`harness-cli`, cùng registry, phase verifier, CI matrix, fixtures và
SPEC/evidence/handoff song ngữ.

User đã yêu cầu rõ commit và push cho assignment này, nên publish được cấp quyền.
Không credential, runtime database hay private trajectory nào được commit.
