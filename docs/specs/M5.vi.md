## 5. Contracts, schema, migrations

- **`ContextChannel`** (`harness-session`): `policy | project_rule | instruction | state | tail | summary | memory | reference | note`. Mỗi `ContextBlock` mang `channel`, `authority: SourceAuthority`, `provenance: Vec<SourceRef>`, `supersedes: Vec<String>`, `digest: ContentHash`. Constructor cũ (`mandatory/optional`) suy ra channel từ `kind` để không phá caller hiện có.
- **Luật hiệu lực:** một instruction có `supersedes` chứa id khác thì block bị supersede bị **loại khỏi** packet (không gửi hai bản); instruction đến từ kênh `summary`/`note`/`reference` **không** trở thành mandatory và không thêm capability.
- **`ContextManifest`**: `{ rendering_version, config_revision, model_id, model_capabilities_digest, tool_definition_digests: Vec<String>, source_revision, channel_digest }`, lưu trong `ContextCheckpointRecord.content` cùng packet + `omitted_optional` + `mandatory_block_ids`/`optional_block_ids`/`superseded_block_ids`.
- **Đo request thật:** `ContextBuildRequest.fixed_request_bytes` (system policy + tool schemas + user text + ảnh) do runtime cung cấp; `token_estimate` = ước lượng trên **toàn bộ** request; overflow mandatory vẫn `MandatoryContextOverflow`.
- **History:** bảng `history_sources(source_id PK, session_id, task_id, project_id, sequence, kind, content, content_hash, availability)`, `history_terms(source_id, term)`; `rebuild_history_index(session)` idempotent; `history_search(scope, query, limit)`; `history_read(scope, source_id, offset, length)`. Term index tất định (lowercase + tách theo ký tự không phải chữ/số, **giữ nguyên** cả identifier có `-`/`_`/`.`), không phụ thuộc FTS5/tokenizer build flag. `availability ∈ {available, expired, foreign}`; `expire_history_source` chuyển một source sang `expired` và `history_read` trả `SourceUnavailable` (ErrorCode mới, `RetryClass::Never`, exit 1).
- **Notes:** bảng `session_notes(note_id PK, task_id, session_id, note_key, revision, content, sources_json, authority)`; `upsert_note_cas` khoá theo `(task_id, note_key)` + `expected_revision`; nội dung/key bounded; `sources` là `SourceRef` (kiểm tồn tại/scope, **không** kiểm tính đúng); `authority` luôn là `model_report`.
- **Lineage/fork/rollback:** `session_lineage` thêm cột `fork_policy` (additive, `ensure_column`); `rollback` ghi event `session.rolled_back` + `RollbackReport`; `fork` ghi lineage edge + grant list và **không** ghi gì vào journal của session con.
  - **Quyết định (ghi rõ vì khác bản nháp đầu):** fork copy một **view**, không copy ownership. Session con chỉ được thêm một row `sessions` (cùng task) để grant scope theo nó; `task_leases`, `task_projections` và `tool_approvals` **giữ nguyên** ở session cha. Hệ quả có chủ đích: con **không** prepare/execute được tool nào cho task (`TaskLeaseConflict`), đọc được đúng source trong grant. Bản nháp "fork ghi event `session.forked` trong journal con" đã bị bỏ: một session con không admit input sẽ không `recover()` được (`journal contains no recoverable admitted input`), và bàn giao lease mà không bàn giao projection sẽ để hai session cùng cho là chủ task. Việc *tiếp quản* task là của `continue_task*` (admit input mới), không phải của `fork`.
- **Migration:** version module mới `CONTEXT_SCHEMA_VERSION=1` (history/notes/lineage policy) theo pattern M4 (`ensure_column` + PRAGMA), DB cũ nâng tại chỗ; host cũ gặp DB mới hơn vẫn từ chối như cơ chế sẵn có.
- **Tools:** `history_search {query, limit?}` và `history_read {source_id, offset?, length?}` — read-only, schema count 11→13, `TOOL_CONTRACT_VERSION` giữ 1 (digest từng tool mới là thứ versioned).

## 6. Invariants / failure modes

1. CAS lấy **trước** generation; candidate dựa revision cũ bị từ chối, rebase bounded rồi `CompactionConflict` — không overwrite decision mới.
2. Không giữ write transaction khi chờ model (summarizer chạy ngoài tx; chứng minh bằng thứ tự gọi trong `compact` + test A12).
3. Mandatory overflow là typed pause, không cắt raw string/không phá tool pairing.
4. Scope filter chạy **trước** rank; source ref ngoài scope ⇒ `ScopeAuthorityDenied`; artifact/event id không phải capability.
5. Fork **không** copy approval một lần, owner generation, lease, projection hay pending effect; chỉ copy refs theo policy. Con không thực thi được gì cho tới khi chính nó sở hữu task.
6. Rollback **không** phải filesystem restore: file vẫn edited, report phải nói external effect retained + evidence stale; undo riêng phải qua gate M4.
7. Note là `model_report`, không phải truth; source check chỉ xác nhận nguồn tồn tại/được phép.
8. Index rebuild cho kết quả **giống hệt** trước rebuild (tất định), và ref hết hạn phải nói rõ.
9. Summary fail/empty ⇒ fallback deterministic, mandatory constraints vẫn còn; không tạo success placeholder.
