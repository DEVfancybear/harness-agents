## 1. Goal / non-goals

**Goal.** Một HTTP surface loopback chạy từ **chính binary `ha`**, xác thực server-side, phát event trên con trỏ
journal bền, và một UI tối thiểu đọc được trạng thái task — tất cả dùng lại service hiện có, không có loop thứ hai
và không có SQL trong adapter.

**Non-goals.** Không multi-user public SaaS; không detach/daemon semantics (đó là M11); không duplicate business
logic ở frontend; không mặc định bind public; không publish.

## 3. Quyết định stack (ADR-N10)

**Không thêm dependency HTTP server nào.** `hyper 1.11.1`, `hyper-util 0.1.20`, `http 1.5.0`, `http-body-util 0.1.5`,
`tower 0.5.3`, `bytes 1.12.1` **đã có trong `Cargo.lock`** (kéo theo bởi `reqwest` của `harness-providers`). Pin đúng
các version đó và dùng `hyper` server + `hyper-util`'s `TokioIo`.

**Lý do:** thêm một HTTP framework mới (axum/warp/actix) là một cây dependency mới trong lockfile cho một server
loopback một người dùng, và P8 §3 chỉ yêu cầu "chọn và pin HTTP/frontend dependencies thật theo tài liệu chính thức".
Dùng crate **đã có trong lock** giữ lockfile ổn định, giữ audit surface không đổi, và vẫn là một HTTP/1.1 server thật
(keep-alive, chunked, streaming body cho SSE) thay vì tự viết parser.

**Frontend:** HTML/CSS/JS tĩnh, **không build step**, nhúng bằng `include_str!` và phục vụ từ cùng binary. P8 §2 cho
phép "chọn frontend stack tối thiểu một cách rõ ràng; runbook không ép framework". Không dev server ⇒ asset phục vụ
đúng version đã build, và CI không cần Node.

## 5. Route surface (M10-01/M10-02)

| Route | Loại | Ghi chú |
|---|---|---|
| `GET /api/health` | read | `{status, schema_version, version}` |
| `GET /api/sessions` | read | danh sách session qua store |
| `POST /api/sessions/{id}/inputs` | **side effect** | admit input qua `SessionService`; đòi `X-Ha-Request-Id`; dedupe theo store |
| `GET /api/sessions/{id}/events?cursor=N` | stream | SSE; `id:` = sequence bền; `gap` event khi cursor < oldest retained |
| `GET /api/sessions/{id}/state` | read | projection đã commit (reload path) |
| `GET /` + `/assets/*` | read | UI tĩnh nhúng |

**Auth:** bind loopback mặc định; mọi mutation đòi header `X-Ha-Session` khớp token sinh lúc khởi động (in ra stdout,
không vào URL/log); `Origin`/`Host` phải nằm trong allowlist loopback. Localhost **không** miễn auth.

## 6. Compatibility

- Không đổi schema/version nào của store hay protocol hiện có. `ha web` là subcommand **mới**.
- Dependency mới: **chỉ** các crate đã có trong `Cargo.lock`; lockfile chỉ đổi nếu một crate trở thành direct dep với
  feature mới. Nếu `Cargo.lock` đổi, ghi rõ trong evidence.
