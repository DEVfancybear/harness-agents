Non-goals: provider/runtime loop (M2/M3), tool OS side effects (M4), memory tables (M7), distributed ownership (M11). Không đổi schema đang persist theo cách phá vỡ database cũ; không đổi data home; không commit/push (assignment M1 không cấp quyền mới).

## 5. Contract decisions (ADR-N02 — lock scope, generation fence, sync/backup, artifacts publish)

Ghi tại `docs/adr/ADR-N02-STORE-OWNERSHIP-DURABILITY.vi.md` (+ `.en.md`):

1. **Lock scope:** `writer.lock` (`fs2` exclusive) là quyền ghi của *một* data directory; một pool 1 connection cho writer để mọi write đi qua một coordinator. Mutex trong process không phải bằng chứng exclusive host.
2. **Generation fence:** mỗi lần mở writer tăng `host_epoch.generation` trong transaction và ghi `hosts(host_id, generation)`; mọi write kiểm tra fence hiện tại trong transaction (`begin_write` + `assert_fence_in_tx`); fence cũ → `StaleWriter`.
3. **Durability:** WAL + `synchronous=FULL` + `foreign_keys=ON` + `busy_timeout=5s`; migration và mọi commit là transaction thật; ACK chỉ sau commit.
4. **Data directory marker:** `harness-data.json` khai báo format version; thiếu → tạo khi mở writer; mới hơn → từ chối ghi, không ghi đè; read-only không cần marker (compat database cũ).
5. **Artifacts publish:** bytes ghi + flush + hash trước, reference commit trong transaction sau; file không reference chỉ bị thu hồi theo reachability + retention pin, không xoá theo suy đoán "log đã capture".
6. **Outbox:** delivery bền dùng `parent_deliveries` (P5) làm outbox logic; không tạo bảng outbox thứ hai ở M1.
