### M10-01 — Authenticated commands/queries

**Files/ownership:** `api/{auth,commands,queries}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Resolve principal server-side; loopback default, session/origin protection for mutation.
2. Command idempotency request IDs scoped with payload hash and shared app services.
3. Generate client types/schema fixtures from contracts; rate/size limits and typed errors.

**Test/oracle:** Forged user/task ownership rejected; duplicate mutation same result, changed payload conflict; no SQL writes in API adapters.

**Invariant và lỗi cần tránh:** Localhost không miễn auth/origin controls.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M10-02 — Events, replay và gap

**Files/ownership:** `api/events.rs; app/projections` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. SSE IDs map durable stream cursor, namespace child vs parent; live buffer bounded.
2. Reconnect reads committed projection/tail, gap explicit when retained range missing.

**Test/oracle:** A33 disconnected/slow subscriber/buffer trim/duplicate and old running after terminal; fresh load equals replayed UI state.

**Invariant và lỗi cần tránh:** Không parse assistant prose hoặc tool text làm lifecycle protocol.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.
