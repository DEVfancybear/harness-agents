### M3-01 — Durable driver và minimum context

**Files/ownership:** `runtime/{driver,state}.rs; store/migrations` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Add run/step/attempt/frozen request records và claims, reserve/freeze atomic boundary.
2. Implement minimum compiler policy+user decisions+state+paired tail+manifest; mandatory overflow stops.
3. Connect provider stream→complete response→fixture ToolExecutor→committed tool results→new step; no user re-admission.

**Test/oracle:** Two-step fixture asserts one InputId, distinct StepIds, frozen retry request hash unchanged; injected store error stops dispatch.

**Invariant và lỗi cần tránh:** Không xây loop trong CLI; M5 mở rộng compiler qua port chứ không thay request path.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M3-02 — Question, approval ports và steering

**Files/ownership:** `runtime/human_input.rs; app/control.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Persist question/request identity/state, pause without holding compute permit; typed answers dedupe scope and expiry.
2. Add command inbox steering/cancel handlers, re-read latest grants at safe boundaries.
3. Ctrl-C graceful drain, cancellation propagation to waiting/provider/tool ports; manual resume checks ownership.

**Test/oracle:** A11 question half với restart/duplicate answer/different payload; full real grant assertions hoàn tất M4; canceled queue không invoke fixture.

**Invariant và lỗi cần tránh:** Không coi timeout/empty answer là consent; A11 vẫn partial cho đến M4.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M3-03 — Durable accounting và loop detection

**Files/ownership:** `runtime/budget.rs; store/accounting.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Implement atomic reservation/settle keyed operation ID và hierarchical limits, checked arithmetic.
2. Measure cumulative/delta usage correctly; unknown pending usage retains conservative bound; retries/summaries accounted by origin.
3. Add max steps/deadline/loop signature frequency + progress changes; all caps typed stop reasons.

**Test/oracle:** Concurrent reservation no over-admit; duplicated usage no double count; missing usage not zero; repeated valid polling fixture không bị false positive theo policy.

**Invariant và lỗi cần tránh:** Đừng giữ SQLite transaction khi await model; model không sửa budget trực tiếp.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.
