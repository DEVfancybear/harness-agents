### M1-01 — Migrations và writer ownership

**Files/ownership:** `store/{schema,owner}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Chọn SQLite crate pin thực tế; enable foreign keys/WAL/busy timeout/sync durability trong connection setup.
2. Tạo versioned migrations + data directory marker; reject unknown newer schema cho writes.
3. Acquire OS/data-directory ownership rồi transaction tăng generation; mỗi write kiểm tra current generation.

**Test/oracle:** Hai independent processes tranh writer; stale token gọi append/finalize bị reject; interrupted migration recover hoặc report rõ.

**Invariant và lỗi cần tránh:** A02; không chỉ dùng Mutex trong một process để chứng minh exclusive host.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M1-02 — Input, inbox và projections

**Files/ownership:** `store/transactions.rs; core/projection.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Create inputs/events/projections/inbox/outbox constraints và immutable event envelope.
2. Implement admit_input với dedupe cùng hash/khác hash, sequence CAS và reducer transaction.
3. ACK sau commit; read APIs load projection + source watermark từ consistent read snapshot.

**Test/oracle:** A01 child ACK→kill→reopen và duplicate changed-payload; inject projection failure rollback cả event lẫn input.

**Invariant và lỗi cần tránh:** Không commit event rồi update WorkingState trong transaction riêng.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M1-03 — Artifacts, checkpoints và replay

**Files/ownership:** `store/{artifacts,checkpoint,replay}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Stage bytes/flush/hash/publish, sau đó transaction insert authorized artifact reference; garbage file chỉ cleanup theo reachability/grace.
2. Checkpoint có source seq, reducer/schema versions và digest; replay tail strictly ordered/idempotent.
3. Unknown critical event block execution, optional audit event bỏ qua có annotation; corrupt snapshot tìm fallback verified.

**Test/oracle:** A05 với corrupt newest checkpoint và unknown critical event; failpoints artifact_publish_before_ref và before_checkpoint_commit.

**Invariant và lỗi cần tránh:** Không suy toàn log đã capture chỉ vì có artifact; không xóa file còn pinned references.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M1-04 — Recovery queries và CLI inspection

**Files/ownership:** `app/recovery.rs; cli/{inspect,replay,export}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Read-only recovery report liệt kê valid state, pending work và blocking reasons; không execute task.
2. Wire inspect/replay/export vào application query ports; stable JSON errors khi schema unsupported.
3. Lập crash matrix M1 và evidence quy định no-provider/no-executor dependencies trong replay.

**Test/oracle:** Fresh process reopen kết quả đúng; dependency/spy counters chứng minh replay zero dispatch; tests M0 regressions.

**Invariant và lỗi cần tránh:** Reopen database không đồng nghĩa chạy lại pending effects; reconciliation execution tới M3/M4.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.
