### M12-01 — Capability spike và backend selection

**Files/ownership:** `execution/backends; ADR-N11` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Evaluate một candidate backend against actual Windows/Linux deployment requirements, document unsupported cases.
2. Threat model host filesystem/env/network/credential sockets/resources and control boundaries.
3. Choose profile + acquire/execute/release port mapping; strict request on unsupported OS fails closed.

**Test/oracle:** Capability probes on real backend, version captured; negative request unsupported profile rejected, no silent host fallback.

**Invariant và lỗi cần tránh:** Không pin backend version từ trí nhớ hoặc đánh dấu platform pass chưa chạy.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M12-03 — Ownership leases và orphan recovery

**Files/ownership:** `execution/backend_lifecycle.rs; store/backend_leases` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Persist lifecycle handle/owner generation before exposed execution; cleanup only verified orphan after grace/reconciliation.
2. Cancel acquire startup safely; background startup and release retain owner state until settled.
3. Release idempotent, export artifacts then cleanup resource handle with receipt; no cross-owner destruction.

**Test/oracle:** Kill during acquire/execute/release; valid peer ownership protected; repeated cleanup idempotent; orphan bounded resource leak.

**Invariant và lỗi cần tránh:** Không dùng local process absence alone để xóa remote resource có live owner.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.
