### M11-01 — Daemon host và IPC

**Files/ownership:** `daemon/{ipc,host}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Same app services + store owner, authenticated per-user local IPC with bounded requests.
2. Client attach/detach doesn't own execution lifecycle; explicit daemon shutdown cancels/drains/checkpoints.
3. Prevent duplicate daemon writer, handle stale endpoint cleanup by verified ownership.

**Test/oracle:** Two daemon startup race, malformed/unauthorized IPC, client exit leaves allowed run alive, daemon stop yields recoverable state.

**Invariant và lỗi cần tránh:** Không clone runtime mới cho daemon.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M11-02 — Durable schedules/occurrences

**Files/ownership:** `daemon/scheduler.rs; store/schedules.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Schedule version/timezone/next_due + occurrence stable key transaction before launch.
2. Define once/interval/cron, DST/misfire/overlap/manual trigger semantics in ADR and injected-clock evaluator.
3. Claim due occurrences bounded queue/capacity and re-evaluate latest pause/delete revision before dispatch.

**Test/oracle:** A34 fake clock spring/fall transitions and restart at claim/launch/settle; manual run preserves future schedule.

**Invariant và lỗi cần tránh:** Wall clock không là idempotency key; lateness không tự tăng catch-up vô hạn.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M11-03 — External task driver và polling

**Files/ownership:** `extensions/tasks.rs; store/external_jobs.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Implement protocol-neutral submit/status/cancel capability with pinned MCP Tasks compatibility if supported.
2. Persist server/task handle/request digest before polling; submission ambiguous without handle requires reconciliation/operator input.
3. Background worker bounded backoff/deadline/cancel, terminal settlement+parent delivery atomic.

**Test/oracle:** A35 timeout after server accepted, restart poll, remote cancel race, terminal result dedupe; no repeated mutation submit.

**Invariant và lỗi cần tránh:** Không LLM spin-loop để poll, không assume remote cancel means effect rolled back.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M11-04 — Non-interactive policy và notifications

**Files/ownership:** `daemon/delivery.rs; app/human_input` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Schedule captures authorized profile/grants/budget, never stronger scope than source user.
2. Missing answer/grant goes waiting/blocked; expiry/next action visible in status.
3. Notification outbox durable dedupe/backoff, meaningful change only; no connector send until configured/authorized.

**Test/oracle:** No-human approval scenario remains blocked; duplicate event yields one logical delivery; A34/A35 gates.

**Invariant và lỗi cần tránh:** Schedule template permission không bao gồm auto approve mọi tool.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.
