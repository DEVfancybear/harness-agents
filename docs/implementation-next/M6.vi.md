### M6-01 — Local skills và activation

**Files/ownership:** `extensions/skills.rs; context/skill_contributor.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Parse metadata/catalog with trusted roots/source digests/conflict IDs; load content only activation/read.
2. Record active skill version and admitted context; persistence/replay uses pinned content or unavailable rõ.
3. Requested tools/secrets remain proposals, no permissions from SKILL text; bound paths/content size.

**Test/oracle:** A22 compact/update/delete skill nguồn; metadata listed but not active; hostile script instruction cannot run without tool authority.

**Invariant và lỗi cần tránh:** Không tự execute scripts lúc scan directory.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M6-02 — Kernel và process protocol

**Files/ownership:** `extensions/{kernel,stdio}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Implement only services có consumer: dependency DAG/scope leases/init rollback/reverse teardown.
2. Define custom versioned protocol frames/IDs/inflight limits/deadlines/cancel/EOF; stdout protocol stderr bounded logs.
3. Minimal child env and generation-scoped registrations; process crash invalidates handles and uncertain calls.

**Test/oracle:** Cycle/missing provider/partial init cleanup; duplicate response IDs/output flood/ignored cancel fail bounded.

**Invariant và lỗi cần tránh:** Transport isolation không là OS sandbox; no retry mutating call on reconnect.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M6-03 — MCP client adapter

**Files/ownership:** `extensions/mcp.rs; tools/external.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Read official spec/SDK release docs at implementation, pin version and feature support matrix.
2. Implement local stdio tools/resources discovery/paging/schema validate and read-only metadata cache.
3. Map invoke/read to shared scope/policy gate and cancellation/resource lifecycle, no direct shortcut tool execution.

**Test/oracle:** A23 malformed schema/frames/unload/crash/timeout; resource text provenance; unsupported extension explicit not advertised.

**Invariant và lỗi cần tránh:** Không suy SDK method existence là app feature supported.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M6-04 — Deferred schema và config explain

**Files/ownership:** `extensions/{catalog,config}.rs; context/tool_contributor.rs; cli` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Expose only authorized catalog names/metadata, promote bounded schemas after search with catalog digest.
2. Recheck policy/schema revisions before execution; invalidate stale promoted definitions on reload/revoke.
3. Config explain source precedence/reload boundary and plugin active/inactive reasons; unload drains/rejects inflight safely.

**Test/oracle:** A24 revoke after discovery and schema change before execution; A22 skill context survived; M4 gate regressions for external calls.

**Invariant và lỗi cần tránh:** No post-freeze injection; discovery permission not invocation permission.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.
