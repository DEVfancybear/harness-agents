### M0-01 — Identities và state reducers

**Files/ownership:** `contracts/ids.rs, core/{task,run,acceptance}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Kiểm kê typed IDs, ScopeContext, enums/reducers và test đang có trong harness-types/session/runtime. Lập bảng requirement → source symbol → callers → tests → gap; chỉ thêm hoặc chỉnh phần thiếu/sai, không tạo crate/domain model song song.
2. Mở rộng reducers hiện có để nhận current state + validated domain command, trả next state + proposed events; cập nhật callers thật và serialization compatibility khi cần.
3. Chốt ErrorCode/retry class và phân biệt run terminal, task accepted, human override.

**Test/oracle:** Table-driven tests phủ mọi cặp transition cho từng machine; terminal cannot regress; completed run + missing criterion không tạo completed task.

**Invariant và lỗi cần tránh:** R01/R02; không dùng stringly typed IDs hoặc timestamp để quyết định ordering.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M0-02 — Ports, envelopes và schema fixtures

**Files/ownership:** `contracts/{event,ports,version}.rs; schemas` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

**Invariant và lỗi cần tránh:** Không fake async IO implementation để thỏa trait; contract-only types chưa là runtime capability.
