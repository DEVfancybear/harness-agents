### M0-01 — Identities và state reducers

**Files/ownership:** `contracts/ids.rs, core/{task,run,acceptance}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Bootstrap `vnext/Cargo.toml` và contracts/core crate manifests tối thiểu nếu chưa có để tests chạy ngay; định nghĩa typed IDs, ScopeContext, enums và transition table với terminal guards.
2. Implement pure reducers nhận current state + validated domain command, trả next state + proposed events.
3. Chốt ErrorCode/retry class và phân biệt run terminal, task accepted, human override.

**Test/oracle:** Table-driven tests phủ mọi cặp transition cho từng machine; terminal cannot regress; completed run + missing criterion không tạo completed task.

**Invariant và lỗi cần tránh:** R01/R02; không dùng stringly typed IDs hoặc timestamp để quyết định ordering.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M0-02 — Ports, envelopes và schema fixtures

**Files/ownership:** `contracts/{event,ports,version}.rs; schemas` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Định nghĩa port methods theo CONTRACTS, chỉ type/future/stream shape cần consumer gần nhất.
2. Tạo versioned envelope và canonical serialization với golden fixture viết độc lập; unknown critical payload có kết quả rõ.
3. Vẽ dependency allowlist, implement test đọc cargo metadata/dependency graph và reject forbidden edge.

**Test/oracle:** Golden decode/encode, unsupported versions, hash order equivalence; negative dependency edge phải fail checker.

**Invariant và lỗi cần tránh:** Không fake async IO implementation để thỏa trait; contract-only types chưa là runtime capability.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

## 3. Acceptance và regressions

Acceptance đến hạn hoặc mở rộng: **contract/schema/state/dependency/gate tests nội bộ M0; A01–A36 vẫn planned**. Xem từng case trong [ACCEPTANCE](ACCEPTANCE.vi.md), gồm setup/trigger/oracle/negative control. Các case nhiều owner chỉ được hoàn tất khi đủ các phần: A11 M3+M4, A19 M5+M7.

Regressions: toàn bộ required suites trong dependency closure (M0 tự kiểm tra contracts và gate negative controls), cộng item-specific cases ở trên. Không mở rộng sang optional milestones chưa triển khai. Đối với OS-sensitive behavior, chạy Windows/Linux hoặc ghi platform pending; không nhận accepted đa nền tảng nếu thiếu required platform proof.

Gate runtime **chỉ tồn tại sau M0 implementation**:

```powershell
pwsh -NoProfile -File vnext/scripts/Verify-Milestone.ps1 -Milestone M0
```

Không dùng docs checker như runtime gate. Missing/ignored required test hoặc exact selector chạy 0 tests phải exit nonzero.
