### M4-01 — Gate, approvals và receipts

**Files/ownership:** `tools/{registry,policy,approval,service}.rs; store/tool_tx.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Define descriptor effect class/schema revisions, validate normalized proposal/scopes.
2. Bind grant to invocation/task/session/principal/action/workspace/revisions; atomic consume+intent.
3. Executor outcome→immutable receipt/projection transaction→model view; observers sau commit không đổi outcome.

**Test/oracle:** A14 grant replay/cross-scope và race consume; A11 approval half; A03/A04 failpoints trước/sau executor/settle.

**Invariant và lỗi cần tránh:** Store failure sau side effect tạo unknown, không failed-no-effect; denied calls không spawn.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M4-02 — Filesystem và Git read/patch

**Files/ownership:** `execution/{files,git}.rs; tools/coding.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Implement bounded read/list/search, patch compare-before-hash và binary/encoding/line ending contracts.
2. Canonical/path handle safeguards cho traversal/symlink/junction/case/locked files, recheck fingerprint gần write.
3. Git status/diff/log dạng structured argv, retain root/base/result fingerprints và explicit dirty state.

**Test/oracle:** A15 stale file/CRLF/Unicode/windows aliases, symlink/junction escape, concurrently changed content; no blanket reset/stash.

**Invariant và lỗi cần tránh:** Path policy không bảo đảm confinement khi shell có toàn host; record host-mode limitations.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M4-03 — Process lifecycle và spool

**Files/ownership:** `execution/{process,spool}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Use structured executable/argv/cwd + environment allowlist; scoped secrets reference resolved just-in-time.
2. Admission permit wait cancellation-aware, recheck before spawn; process tree own/terminate/reap cả output drain.
3. Bounded artifact spool/header-tail previews/read paging, disk/quota failures typed; avoid memory-only whole-log buffer.

**Test/oracle:** A13 canceled queued marker; A16 grandchild cleanup/timeout/env credential sentinel; A17 tail marker/disk-full/truncation assertions.

**Invariant và lỗi cần tránh:** Nếu cleanup chưa confirmed thì receipt uncertainty; không ghi tree_cleanup=true chỉ vì kill request thành công.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.
