### M7-01 — Assets và authority

**Files/ownership:** `memory/assets.rs; store/memory_schema.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Define asset/version/scope/source dependency/grants/binding/status fields and CAS publication.
2. Separate propose from publish, user corrections/source changes create new versions not overwrite audit.
3. Read/search/export all resolve host ScopeContext; no forged project/actor args.

**Test/oracle:** Concurrent version expectation conflict; same content different project no cross-read; unknown source reject candidate.

**Invariant và lỗi cần tránh:** No confidence threshold can bypass permission or validate truth.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M7-02 — Durable extraction consumer

**Files/ownership:** `memory/extraction.rs; store/jobs.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Enqueue source ranges after committed journal, dedupe by scope/range/extractor version.
2. Lease claims bounded retries/backoff, settle candidates/dispositions/cursor in transaction with generation check.
3. Extraction budget lower priority, cancellation and disabled extractor retain queue; explicit catch-up command.

**Test/oracle:** A25 kill before/after publish settlement, duplicate claims, failed/filtered source dispositions; A19 extractor failure no blocked resume.

**Invariant và lỗi cần tránh:** Không giữ queue solely timer/list trong process hoặc dùng notification làm durability.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M7-03 — Retrieval và invalidation

**Files/ownership:** `memory/{retrieval,invalidation}.rs; context/memory_contributor.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. FTS scope/status filters trước rank and token-bound candidate selection with source freshness check.
2. Apply corrections/supersedes/revocation, dependency invalidation for summaries/indexes.
3. Stamp selected version/reason/digests in packets; injected memory không thành independent extraction source.

**Test/oracle:** A26 stale file source/user correction/revoked asset; verify latest packet không chứa revoked content; CAS across workers.

**Invariant và lỗi cần tránh:** HistoryReader phục hồi task vẫn hoạt động nếu memory provider unavailable.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.
