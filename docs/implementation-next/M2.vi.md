### M2-01 — Typed messages và capability registry

**Files/ownership:** `providers/{messages,capabilities}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Implement typed assistant calls/tool results và validate correlation, duplicate IDs, ordering.
2. Define FrozenRequest serializable + model/capability/config revision; resolve secret ngoài payload.
3. Capability validation reject unsupported params; distinguish unknown, explicitly false và supported.

**Test/oracle:** Golden multi-turn tool transcript, orphan result, ID reuse trong step và unsupported option đều có oracle độc lập.

**Invariant và lỗi cần tránh:** Không flatten tools thành User text để adapter dễ code.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M2-02 — SSE assembler có state

**Files/ownership:** `providers/assembler.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Parse bytes→UTF8/frame→provider payload→normalized deltas, giới hạn bytes/frame/calls/args.
2. Maintain call accumulation theo choice/index, retain ID/name, detect conflict và terminal incomplete args.
3. Separate terminal/finish/usage-only/EOF/length/refusal; expose bounded incremental stream backpressure.

**Test/oracle:** A06 permutations chunk boundaries/multiple indexes/text+tool frame; slow consumer không unbounded growth; truncated JSON không thành valid call.

**Invariant và lỗi cần tránh:** Không lấy tool_calls[0] hoặc fabricate fallback call ID rồi execute.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M2-03 — Transport, DeepSeek và cancellation

**Files/ownership:** `providers/{transport,deepseek,mock}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Kiểm tra docs DeepSeek chính thức ở lúc implementation, pin supported model/API matrix trong SPEC; endpoint configurable.
2. Implement streaming HTTP/auth ref/timeouts và error taxonomy; retries do layer owner rõ để không nhân đôi retry loops.

**Invariant và lỗi cần tránh:** Không fallback sang model/provider khác nếu profile chưa cho phép.
