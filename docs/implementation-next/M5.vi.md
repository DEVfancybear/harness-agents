### M5-01 — Context channels và manifest

**Files/ownership:** `context/{compiler,contributors}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Extend minimum compiler bằng channel types và authority/provenance, effective instructions/supersedes.
2. Snapshot single effective config/model/tool definitions/source revision và proposed optional blocks.
3. Measure entire serialized request with output reserve/margins; freeze records incl omissions/source digests.

**Test/oracle:** Injected summary/notes fake host instructions không tăng capabilities; full schema-heavy request respects cap; mandatory overflow typed pause.

**Invariant và lỗi cần tránh:** Không clip raw string để fit rồi phá tool pairing/constraints; post-freeze mutation bị hash/validation phát hiện.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M5-02 — Compaction generation và CAS

**Files/ownership:** `context/compaction.rs; store/checkpoint_tx.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Capture original source seq trước generation; choose valid tool-paired tail và structured mandatory state.
2. Generate bounded summary with model-specific request budget, fallback deterministic when fail/empty.
3. Validate candidate, CAS/checkpoint publish, stale conflict bounded rebase hoặc pause, không giữ write lock lúc LLM.

**Test/oracle:** A12 barrier correction arrives during generation; A19 summary failure; compare checkpoint source seq/decision winner.

**Invariant và lỗi cần tránh:** CAS lấy sau generation là lỗi dù transaction write atomic.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M5-03 — History index, exact reads và notes

**Files/ownership:** `context/{history,notes}.rs; store/history.rs; tools` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Index journal as rebuildable FTS, source refs contain identity/digest/lineage and availability.
2. Search scope before rank, exact paged source reads; tiếng Việt/identifiers tests độc lập tokenizer choice.
3. Notes bounded keys/content/sources, CAS updates model_report authority; source check != truth validation.

**Test/oracle:** A18 exact identifier absent summary but in source; A20 foreign source denied; index rebuild identical accessible results; expired refs explicit.

**Invariant và lỗi cần tránh:** Không dùng unrestricted filesystem read để resolve SourceRef; no embeddings needed.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M5-04 — Resume/fork/rollback và workspace staleness

**Files/ownership:** `context/lineage.rs; app/session.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Recover journal/WorkingState, re-observe workspace and mark stale evidence trước new packet.
2. Fork permitted source lineage into new session IDs/grants policy, never copy one-shot approval/owner.
3. Rollback chỉ thay conversational branch, external effects retained/flagged; optional undo là separate gated action.

**Test/oracle:** A20 fork grant/scopes, A21 file survives checkpoint rollback, A18 restart after five compactions; M4 side-effect regressions.

**Invariant và lỗi cần tránh:** Không gọi rollback thành filesystem restore khi chưa implement explicit undo.
