### M9-01 — Backup, restore và retention

**Files/ownership:** `crates/harness-maintenance/src/{backup,retention,migration}.rs; store` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Consistent SQLite backup + referenced artifact manifest/version/hash; restore into new dir then validate activate.
2. GC mark/sweep from pinned active tasks/checkpoints/lineage/receipts with grace, scoped delete/archive semantics.
3. Versioned migration failure recovery; unsupported downgrade/write rejected, preserve source backup.

**Test/oracle:** A31 restore active/recent checkpoint+artifact, fork ancestor pins, interrupted migration, corrupt backup rejected without overwriting destination.

**Invariant và lỗi cần tránh:** Không copy chỉ db file khi WAL active, hoặc GC bằng mtime độc lập reachability.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.
