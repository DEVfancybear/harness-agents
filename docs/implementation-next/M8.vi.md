### M8-01 — DAG, scheduling và briefs

**Files/ownership:** `orchestrator/{dag,scheduler}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Typed immutable TaskBrief with criteria/source refs/capabilities/workspace scope/budget.
2. Reject cycles/depth overflow; queue bound, per-role compute/model/process limits và timeouts.
3. Parent wait releases compute permits; reserve hierarchical budgets before child claim/dispatch.

**Test/oracle:** A27 cycles, queue full, three children budget edge, parent waits without starvation; stable snapshot no copied parent tool calls.

**Invariant và lỗi cần tránh:** Không giữ model/process permit trong idle actor hoặc đặt unlimited spawn default.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M8-02 — Result và parent delivery

**Files/ownership:** `orchestrator/delivery.rs; store/child_tx.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

1. Child uses same runtime engine; correlate child execution with parent task/tool call and lineage.
2. Commit child result+evidence refs+parent inbox delivery transaction, notification best-effort.
3. Receiver dedupe conditional transition, resume scans pending results và verifies owner generation.

**Test/oracle:** A28 kill parent after commit before notify; duplicate delivery remains one accepted logical result; child stale owner can't finalize.

**Invariant và lỗi cần tránh:** Không semantic search để biết child đã done.

**Done cho item:** behavior nối vào consumer ở mốc này, targeted tests thực sự chạy và SPEC/handoff được cập nhật. Không đồng nghĩa toàn milestone accepted.

### M8-03 — Worktree ownership và integration

**Files/ownership:** `orchestrator/{workspaces,integration}.rs` — shorthand theo bảng path map trong [sổ tay](README.vi.md); ghi actual paths ở SPEC.

**Thực hiện:**

**Invariant và lỗi cần tránh:** Worktree is concurrency boundary, not strict security sandbox.
