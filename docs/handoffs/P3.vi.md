## Quy trình khởi động lại

1. Đọc handoff này, [evidence P3](../evidence/P3.vi.md), [SPEC P3](../specs/P3.vi.md), [runbook P3](../implementation/P3_CODING_TOOLS.vi.md) và các contract được link.
2. Chạy `git status --short` và `git diff --check`; giữ thay đổi không liên quan. Không reset hoặc clean repository để restart.
3. Chạy `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings` và `cargo test --workspace --all-targets --locked`.
4. Chạy `pwsh -NoProfile -File scripts/Verify-Docs.ps1 -SelfTest` và `pwsh -NoProfile -File scripts/Verify-Phase.ps1 -Phase P3 -Json`.
5. Build và inspect capability keyless bằng `cargo build -p harness-cli --bin ha --locked` và `target\debug\ha.exe code capabilities --json` (PowerShell path có thể khác).
6. Xác nhận `git rev-parse HEAD`, `git ls-remote origin refs/heads/master` và kết luận cuối GitHub Actions cho SHA đã push. Gate local xanh không chứng minh remote hay production activation.
7. Khi restart gặp tool intent pending, inspect intent durable rồi chỉ gọi `ToolExecutionService::reconcile_pending` sau khi kiểm tra post-state workspace. Hàm này không dispatch action đã lưu lần nữa; outcome không exact vẫn ở `outcome_unknown` để user xử lý.

## Guardrail và gap rõ ràng

- Giữ schema version 1, identifier P0/P1/P2, canonical hash, single-writer transaction boundary, task/session ownership và frozen P2 request.
- Approval single-use bind actor, action canonical, root/fingerprint workspace, policy revision và tool revision. Ancestor deny vẫn monotonic; strict isolation vẫn deny trên host này.
- Không thêm P4 memory extraction, P5 multi-agent scheduling/delegation, P6 plugin, P7 release/deployment hay P8 Web UI trong phase này.
- Chưa dùng provider credential thật, chưa smoke external network, chưa chạy Linux local, coverage/mutation/audit, release package, deployment hay production activation. Đây là gap rõ ràng, không phải claim pass.
- Lần RED process đầu lộ race lifecycle Windows; runner cuối dùng một terminal wait, kill/reap bounded và host mutex. Giữ contract lifecycle này khi mở rộng tool.

Bước an toàn tiếp theo là phase P4 được cấp quyền riêng. Dừng tại đây cho đến khi có assignment, SPEC, predecessor evidence và gate mới.
