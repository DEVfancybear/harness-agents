## 4. P7 surfaces P8 must not bypass

- **`ha` is installed, not vendored.** `scripts/Install-Ha.ps1` puts one binary on
  `PATH`; it downloads nothing and edits no environment variable. A future
  packaging phase may add real release artifacts, but nothing here may be described
  as published until that exists.
- **A data directory with no store is a first-run state.** `doctor` reports it as
  uninitialized and writable; that is not permission to assume data exists, and
  `backup` still refuses such a directory.

- **One writable host.** `SqliteStore::open_writer` takes the OS file lock and a
  host fence generation. A Web adapter must call application services; it must
  not open the database directly, and it must not treat a read-only handle as a
  write path.
- **`invalidate` is not `delete`.** An invalidation keeps the historical record.
  Only `forget` removes content, it requires confirmation equal to its target, and
  it writes a tombstone that blocks re-extraction.
- **A restore never activates.** `restore_backup` writes a fresh directory with
  `"activated": false`. Activation stays an explicit operator decision.
- **Migration runs on a copy.** `migrate_copy` never mutates the source, and a
  store newer than the binary is refused for writes while read-only inspection
  keeps working.
- **GC honours pins.** An artifact that a backup or an unfinished task pinned is
  never collected, and the grace period is checked with the pin inside the same
  read.
- **The release matrix is the honest surface.** A UI that renders platform,
  capability or benchmark status must render `unverified`, `component_only`,
  `unsupported` and `measured: null` as such, never as success.
- **The policy gate from P3 and the extension trust contracts from P6 stay the
  only authorization paths.** P7 adds maintenance operations, not a new way to
  execute or to widen authority.

## 5. Known limitations

- No daemon, no scheduled collection and no background retry: every maintenance
  action is foreground. A forgotten source stays forgotten only while its
  tombstone exists in a store that is still used.
- `forget` is local. External and backup copies are **not** reachable; the tool
  records the copies an operator declares and reports them back.
- The writer lock is an OS advisory lock, so it is bound to the running host and
  is meaningless once copied to other media.
- Backups are single-directory snapshots. There is no incremental backup, no
  catalog and no remote target.
- The `ha maintenance` command group replaces the `ha doctor` / `ha backup` /
  `ha restore` / `ha retain` / `ha gc` command names sketched in the runbook: they
  are subcommands, and the operator guides document the shipped form.
- Security tooling (coverage, mutation, audit, secret scan) was not run; treat any
  claim outside the gate record as unverified.
