# Restart handoff P6

## 1. Ranh giới

Đã triển khai P6-S01 đến P6-S07; phase gate local pass. **P7 chưa bắt đầu.**
Commit và push đã được user yêu cầu rõ cho assignment này; trạng thái publish và
CI remote thật được ghi ở mục 7 của [evidence](../evidence/P6.vi.md), không được
khẳng định ở đây. Đọc [SPEC](../specs/P6.vi.md) và [evidence](../evidence/P6.vi.md).

Base là `0ba1a10` trên `origin/master`. P5 đã được xác minh lại từ source trước
khi viết bất kỳ code P6 nào: digest
`sha256:761ce949f3f218410899b540eb3872ba660a4a79d58086e26a71c14fcf4c2706`
(171 file, 19/19 required test), và CI remote run `35109453587` xanh cho P5 trên
ubuntu-latest và windows-latest. P6 được kiểm thử tại digest
`sha256:7d2f8b1a938d734cea485091755bf914c3723b5dcc629822ab5ca1817d4eb854`
(192 file).

## 2. Đã xác minh và còn mở

Xác minh local: `cargo fmt --all -- --check`, `cargo clippy --workspace
--all-targets --locked -- -D warnings`, `cargo test --workspace --all-targets
--locked`, `cargo test -p harness-cli --test phase_p6 --locked` (15 passed,
0 failed, 0 ignored) và `scripts/Verify-Phase.ps1 -Phase P6 -Json` (passed,
12/12 required, 15 discovered, regression tiền nhiệm P0 8 / P1 24 / P2 17 /
P3 19 / P4 21 / P5 19). Các CLI path `ha extensions` được chạy bên trong phase
target với binary thật.

Còn mở: CI remote trên ubuntu-latest và windows-latest đang
**pending push mà assignment này cho phép**; bản ghi này không biết run id, và phải
xác nhận bằng `gh run list --commit <sha>` trên revision đã push. Mutation testing, coverage,
advisory audit và secret scan rộng chưa chạy vì tooling không được cài ở đây.
Docs self-test không được ghi cho assignment này. Remote MCP endpoint và model API
trả phí là absent theo thiết kế: MCP được chạy với fixture MCP server local qua
stdio thật bằng official SDK. Không dùng agent xác minh độc lập vì việc spawn
agent không được giao, nên đây vẫn là self-verification.

## 3. Tiếp tục chính xác

1. Kiểm `git status --short` và `git log -1`; xác nhận không file ngoài dự kiến bị
   đụng và revision đã push chính là revision gate đã kiểm thử.
2. Chạy lại phase gate và ghi source digest được in ra; mọi thay đổi sau lần gate
   cuối làm digest trước đó thành stale.

   ```powershell
   pwsh -NoProfile -File scripts/Verify-Phase.ps1 -Phase P6 -Json
   ```

3. Ghi trạng thái remote thật cho commit đã push; thay `<sha>` bằng revision thật
   trước khi khẳng định bất kỳ kết quả CI nào.

   ```powershell
   gh run list --commit <sha>
   ```

4. Nếu muốn commit hay push thêm thì phải được yêu cầu rõ.
5. Không bắt đầu phần việc P7, và không coi local pass là evidence CI hay release.

## 4. Bề mặt P6 mà P7 không được bỏ qua

- Transport và handshake: `harness_extensions::ExtensionTransport` cùng
  `ExtensionHandshake` và `NegotiatedSession`. Các bound đã pin
  (`EXTENSION_PROTOCOL_VERSION = 1`, `MAX_FRAME_BYTES = 1 MiB`,
  `MAX_STDERR_BYTES = 64 KiB`, `MAX_INFLIGHT_CALLS = 4`, `HANDSHAKE_TIMEOUT_MS = 5000`,
  `DEFAULT_CALL_TIMEOUT_MS = 30000`, `MAX_SKILL_BYTES = 256 KiB`) không được nâng
  lên một cách im lặng. Frame oversize là protocol error, stdout chỉ mang protocol
  frame, và call không bao giờ nhận được response thì vẫn uncertain thay vì thành
  success được dựng ra.
- Trust: `TrustGrant` được pin theo principal, theo digest và theo capability, và
  `ExtensionRuntime::load` phải vẫn là entry point duy nhất start process. Grant
  chỉ có thể thu hẹp qua `intersect`, không bao giờ mở rộng. Không gì được start
  executable hay resolve secret mà không có trust grant rõ ràng ở mức user, và
  process plugin chỉ được thấy `ENVIRONMENT_ALLOWLIST` cộng override rõ ràng.
- Bề mặt host method: `HOST_METHOD_ALLOWLIST` — `host.echo`,
  `host.workspace.observe`, `host.task.read`, `host.memory.search`. Method xin
  ngoài allowlist bị từ chối `HostMethodDenied`; không thêm method vào allowlist
  như một cách cho tiện.
- Policy gate: external tool chỉ thực thi qua
  `harness_tools::ToolExecutionService::prepare` và `execute` với
  `CodingToolAction::ExternalTool` cùng dispatch hook `ExternalToolDispatcher`,
  hook này nằm sau durable intent commit. Không có authorization path thứ hai, và
  nested call giữ parent invocation id để correlation.
- Vòng đời và generation: registration đi qua `harness_kernel::ScopedRegistry`.
  Unload/reload gắn với generation, nên disposer muộn từ generation cũ không thể
  gỡ bản thay thế, và remount không bao giờ cho phép lặp lại một side effect.
- Skills: `discover_skills`, `compose_skills` và `SkillVersionPin`. Nội dung skill
  là data và không thể mint tool permission; skill update chỉ hiện ra ở một
  boundary được ghi lại, và text skill chỉ vào context qua P2 context builder.
- MCP: `harness_extensions::McpClient`. Negotiation của MCP thuộc contract của
  official SDK và không bao giờ được coi là tương thích với plugin protocol tự
  định nghĩa; schema đổi thì phải renegotiate trước khi dùng, và MCP tool đi qua
  đúng P3 gate với registration có scope.
- CLI: `ha extensions inspect|capabilities|register|skills` là bề mặt đăng ký local
  duy nhất được hỗ trợ. `register --confirm` cùng trust file mới activate được thứ
  gì đó; chỉ inspect thì không start process nào.

## 5. Known limitations

Transport isolation là một protocol bị chặn biên cộng môi trường tối thiểu và
method surface nằm trong allowlist, khai rõ **không phải** OS sandboxing cho native
code không tin cậy. Remote MCP endpoint ngoài scope, cùng với marketplace, Wasm,
arbitrary native dynamic loading và external loop hay storage plugin. Mutation
testing, coverage, advisory audit và secret scan rộng chưa chạy vì tooling không
được cài. Một external dependency đã được thêm (`rmcp =3.4.0`, Apache-2.0) và
không có khẳng định nào về advisory cho nó. Chỉ kết quả gate local được ghi trừ khi
có chú thích, và phần việc này là self-verification không có agent độc lập.
