## 3. Tiếp tục chính xác

1. Kiểm `git status --short`, `git log -1`, remote SHA và verifier đang chạy.
2. Nếu verifier không còn chạy, chạy:
   `pwsh -NoProfile -File scripts/Verify-P4Gauntlet.ps1`.
   Lệnh chạy manual mutants có receipts/restored suites, P4 gate và regressions P0–P3.
3. Ghi JSON digest/counts cuối; sau khi chỉ sửa evidence, kiểm docs:
   `pwsh -NoProfile -File scripts/Verify-Docs.ps1 -SelfTest`.
4. Kiểm Actions thực tế bằng `gh run list --commit <pushed-sha>` và
   `gh run view <run-id>`; CI matrix gồm P0/P3/P4 trên Ubuntu và Windows.
5. Commit/push riêng evidence/handoff sau kiểm chứng. Không nhận phase hoàn tất
   nếu gate bắt buộc fail hoặc thiếu required platform checks.
6. Dừng trước P5, cần assignment mới.

Memory schema revision 1 là bổ sung, dùng coordinator hiện có. Không commit runtime
DB/private trajectories. Coverage/advisory scan và gaps review P0–P3 kế thừa đã ghi
rõ trong evidence, không coi ngầm là pass.
