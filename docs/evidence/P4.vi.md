## 2. Ownership và contracts

[SPEC](../specs/P4.vi.md) ghi dependencies, failure model và negative constraints.
`harness-memory` sở hữu policy/extraction/retrieval/invalidation. Memory schema
SQLite bổ sung revision **1** gồm assets, immutable versions, grants, bindings,
dependencies, jobs, contiguous cursors, FTS5 và revision/audit, qua single writer/
host fence hiện có. Giữ nguyên event/ID/schema versions cũ. Runtime kiểm tra trước
mỗi provider attempt; chỉ P2 admission/freeze context và ghi memory refs thực sự
được nhận. CLI, registry, verifier và CI chỉ mở rộng đến P4.

Principal/scope flags là local host inputs được tin cậy; không expose trực tiếp
cho model tự điều khiển. Rendering seal riêng phát hiện sửa contribution, không
phải isolation khỏi code bất kỳ trong host process.
