## 6. Crash/failpoint test

- `m0_04_child_fixture_failpoint_protocol`: process con thật (`m0_fixture_host`) giữ writer lock, in readiness line, admit input (commit durable), ghi marker rồi **exit 86** — code riêng, không trùng success/error thường. Parent đọc 3 dòng JSON theo thứ tự và assert marker.
- Failpoint controller nằm trong **test-helper binary**, không có nhánh failpoint nào trong `ha`; do đó không thể bật trong production path (mạnh hơn feature-gate, cùng chuẩn với `p1_fixture_host`/`p6_fixture_*`).
- Crash tests cũ (`phase_p1` child-kill sau ACK / sau receipt) vẫn pass sau khi `SessionService` nhận `IdSource` inject.
- Flake đã biết: `p3_s04_process_output_timeout_cancel_and_descendant_cleanup_are_bounded` fail một lần khi chạy tay dưới tải (`assertion failed: started.elapsed() < Duration::from_secs(5)`), pass lại khi chạy riêng (13.1s) và pass trong gate. Đây là bound 5 giây trên máy đang bận, đã được ghi nhận trong commit `bebc6cc` của người dùng; M0 không sửa.

## 7. Compatibility / migration / source scope

- **Không** đổi schema `SQLite`, không migration, không đổi data directory/config path. `RUNTIME_SCHEMA_VERSION` vẫn 1.
- JSON **thành công** của mọi command giữ nguyên (test P1/P2/P4/P6 xanh).
- Đổi có chủ đích, đã khóa bằng fixture/test:
  1. Exit code lỗi theo `ErrorCode::exit_code()` (2/3/4/5/130/1) thay cho luôn 1 — theo CONTRACTS §9; `tests/fixtures/m0/cli/exit-codes.json` + `m0_01_*` khóa mapping.
  2. `--json` của subcommand legacy in JSON error report ở **stderr** (prose giữ nguyên khi không `--json`); stdout vẫn chỉ chứa kết quả.
  3. Bộ schema công bố thêm `schemas/error-report.v1.schema.json` (9→10); `p0_f03` cập nhật đúng số lượng, drift check không đổi.
  4. `AgentState::transition` nhận `RunCommand` thay vì state đích; `phase_p2::p2_s01` cập nhật theo (cùng semantics).
  5. `harness-orchestrator::DelegatedResult::accepted_completion` dùng acceptance reducer dùng chung; strict hơn ở đúng một điểm: report `Completed` **không** có artifact/receipt giờ không được coi là accepted (trước đây `accepted_completion` trả true rồi bị `EvidenceVerifier` từ chối với message khác). Error code vẫn `ResultIncomplete`.
- Không xóa/đổi field persisted nào; `EventEnvelope`, `WorkingState`, `ToolExecutionReceipt` giữ nguyên chữ ký.

- **Console-only tests:** 17 test PTY + 1 test ACL vẫn `ignored` như baseline; cần `scripts/Invoke-HaPtyAcceptance.ps1`/môi trường thật.
- **Dependency checker:** đọc manifest của `crates/*` (kể cả `[target.*]`), không dùng `cargo metadata`; `[workspace.dependencies]` không phải edge nên không kiểm — đúng phạm vi "edge nội bộ giữa crate".
- **Clock injection:** hoãn sang M3 (M0 không có consumer wall-clock); chỉ `IdGenerator` được inject.
- **Paid smoke:** không chạy (không thuộc M0, không có credential).
