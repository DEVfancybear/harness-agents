## 6. Crash / compatibility assertions

- **Parent chết sau commit, trước notification** (A28): delivery vẫn `pending` trong store; reopen đọc đúng result; `durable_progress` trả `Completed`. Không có đường nào "biết child đã xong" bằng tìm kiếm ngữ nghĩa.
- **`SchedulerConfig` cũ** (compat): field mới `max_queued_workers` có `#[serde(default = "default_max_queued_workers")]` trỏ về default của host (8), **không** phải 0. 5 fixture P5 được cập nhật tường minh và vẫn xanh 27/27.
- **Error code mới**: `DelegationQueueFull` buộc phải khai báo ở `retry_class` (`HumanAction`) và `exit_code` (3) — match toàn phần nên compiler ép.
- **CLI**: `ha tasks run --json` chỉ **thêm** field; `p5_s07` vẫn xanh.
