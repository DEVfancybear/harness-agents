## 2. Ownership and contracts

[SPEC](../specs/P4.en.md) defines dependencies, failure model and negative constraints.
`harness-memory` owns policy/extraction/retrieval/invalidation. Additive SQLite
memory schema revision **1** owns assets, immutable versions, grants, bindings,
dependencies, jobs, contiguous cursors, FTS5 and revision/audit records through the
existing single writer/host fence. Existing event/ID/schema versions are preserved.
Runtime validates before every provider attempt; P2 alone admits/freezes context
and records only admitted memory refs. CLI, registry, verifier and CI extend through P4.

Principal/scope flags are trusted local host inputs; never expose them directly to
model-controlled arguments. The private rendering seal detects post-contribution
edits; it is not isolation from arbitrary code inside the host process.
