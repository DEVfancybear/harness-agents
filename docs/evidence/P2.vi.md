## Ranh giới đã bàn giao

- `harness-types` thêm runtime ID có version và error code provider/runtime/context ổn định, giữ nguyên schema version 1 của P0/P1.
- `harness-providers` cung cấp role/message/stream event đã normalize, provider boundary object-safe, MockProvider xác định được, cancel có giới hạn, SSE decoder incremental tương thích OpenAI, DeepSeek HTTP adapter và credential resolver isolation. Tool delta chỉ được ghép làm evidence; không thực thi tool.
- `harness-store-sqlite` thêm runtime schema revision 1 theo kiểu additive (không đổi `STORE_SCHEMA_VERSION=1`), command/claim bền vững, agent state, composition snapshot, context packet/checkpoint, frozen request, provider attempt, lineage, CAS và stale-generation takeover.
- `harness-session` thêm admission context bắt buộc/tùy chọn, token budget xác định được và giải thích overflow, source manifest, decision supersession và fold runtime event.
- `harness-runtime` sở hữu admission → context → composition → frozen request → provider attempt có persistence, retry/cancel, compaction fallback xác định được, resume, continuation và offline replay.
- `harness-cli` thêm `run`, `resume`, `continue`, `context inspect` và `session replay --offline` không cần key; output metadata P1 cũ vẫn tương thích.
