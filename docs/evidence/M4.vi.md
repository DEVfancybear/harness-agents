## 7. Limitations / việc còn lại

- **M4-02.2 (locked-file typed error): chưa commit được.** `hash_file` trong HEAD vẫn map mọi lỗi (kể cả lock của process khác) thành `WorkspaceEscape`; bản sửa đúng (lock → `Ok(None)` "present-but-unreadable", lỗi khác → `StorageOpenFailed`) **đang nằm trong working tree nhưng thuộc một session khác** (xem §8) nên M4-02 chưa thể gộp. Không dùng `git add -A`; nếu session kia dừng, cần xác nhận trước khi adopt.
- M4-03: permit queue cancellation-aware (A13), env allowlist + secret JIT (A16), tree cleanup trung thực + Windows grandchild test, output spool/page/quota (A17) — các file `process.rs`/`service.rs` đang bị session khác sửa ở `process.rs`, cần chờ hoặc phối hợp.
- M4-04: digest-bound check evidence + `a08_coding_e2e`; A03/A04 child-kill fixtures đã có từ M4-01b.
- StorePort vẫn chưa implement (handoff M3); Linux gate/live smoke không chạy; host flake có retry một lần ở bước workspace-tests.
- Test harness: `milestone_m2::collect` thêm retry có giới hạn theo đúng chữ ký loopback-refusal (gate M4 lần đầu fail ở closure-M2 vì flake này); không nới assertion, mọi lỗi khác fail ngay (SPEC §11).
