## Delivered boundary

- `harness-types` adds versioned runtime IDs and stable provider/runtime/context error codes while preserving P0/P1 schema version 1.
- `harness-providers` provides normalized roles/messages/stream events, object-safe provider boundary, deterministic MockProvider, bounded cancellation, incremental OpenAI-compatible SSE decoder, DeepSeek HTTP adapter, and credential resolver isolation. Tool deltas are assembled as evidence only; no tool is executed.
- `harness-store-sqlite` adds additive runtime schema revision 1 (without changing `STORE_SCHEMA_VERSION=1`), durable commands/claims, agent states, composition snapshots, context packets/checkpoints, frozen requests, provider attempts, lineage, CAS checks, and stale-generation task takeover.
- `harness-session` adds mandatory/optional context admission, deterministic token budgeting and overflow explanation, source manifests, decision supersession, and runtime event folding.
- `harness-runtime` owns persisted admission → context → composition → frozen request → provider attempt, retry/cancel, deterministic compaction fallback, resume, continuation, and offline replay.
- `harness-cli` adds keyless `run`, `resume`, `continue`, `context inspect`, and `session replay --offline`; existing P1 metadata output remains backward-compatible.
